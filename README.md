# 📖 Overview

Sales Intelligence Hub is a modern business analytics and financial tracking system designed for multi-branch sales operations.

The platform enables organizations to:

* monitor branch-wise revenue
* track pending collections
* manage split payments
* visualize KPIs in real time
* generate business intelligence reports

Built with a scalable modular architecture and enterprise-style authentication system.

# ⚡ Installation

```bash
# Clone repository
git clone https://github.com/sivadst/sales_intelligence_hub.git

# Move into project directory
cd sales_intelligence_hub

# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run app.py
```
